# ケトパパキャラクター参照

ChatGPT用のケトパパ（薬剤師キャラクター）参照画像リポジトリーです。

## キャラクター概要
- 種類: 犬（ポメラニアン系）
- 職業: 薬剤師
- 性格: やさしい・丁寧
- 体色: クリームホワイト
- チャームポイント: 頭の双葉、ふわふわの毛並み、白衣と黒帯、緑の十字ポケット

詳細設定は [CHARACTER.md](CHARACTER.md) を参照。

## 参照画像（上傳予定）
- ketopapa.jpg : ケトパパ単体（クリップボード持ち）
- 05_ケトパパ_詳細設定シート_v01.jpg : 詳細設定シート
- 08_ケトパパ_ポポンタ_比較シート_v01.jpg : ケトパパとポポンタの比較シート
- pharmacy-scene.jpg : 薬局の人員不足を数字で伝えるイラスト

※ 画像ファイルはバイナリのため、このツールから直接アップロードが難しいので、お手数ですがGitHubウェブからドラッグ＆ドロップで追加してください。既存の詳細シート等は fire-os リポジトリの assets/ketopapa-friends/ にもあります。

## 参照ルール
- 設定文だけでキャラクターを生成しない。
- 正本画像を確認せず、一般的な犬の特徴で補完しない。
- 顔型、耳、目、毛色、頭身、衣装、小物、画風を固定する。
- ChatGPTのカスタムGPTやノウハウジーにこのリポジトリURLを追加すると使いやすいです。
